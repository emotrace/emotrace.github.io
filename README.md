# EmoTrace

Project page for **Hierarchical Masked Diffusion Transformer for Fine-Grained Temporal Speech Emotion Recognition**.

The initial page contains the paper title, model framework teaser, and abstract.

Website: https://emotrace.github.io/

## Editing

This is a static website with no build step. Edit `index.html` for page content and `site.css` for presentation. The framework is provided as `teaser.png` and the original `teaser.pdf`. All website files are stored at the repository root for direct GitHub Pages deployment.
